# El Shamy Market

واجهة متجر عربي RTL تجريبية للشامي ماركت، تشمل:
- عرض المنتجات والأقسام والبحث.
- سلة مشتريات.
- بيانات العميل والعنوان.
- إرسال الطلب عبر WhatsApp.
- الدفع عند الاستلام.
- لوحة إدارة محلية لإضافة وتعديل وحذف المنتجات والأقسام.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل مجلد المشروع باستخدام Live Server في VS Code.

## إعداد واتساب والتوصيل
افتح `config.js` وعدّل:
- `whatsapp`: رقم واتساب بصيغة دولية بدون + أو مسافات. مثال مصر: `2010XXXXXXXX`.
- `deliveryFee`: رسوم التوصيل بالجنيه.

## تعديل المنتجات
يمكن تعديل المنتجات والأقسام من `admin.html`. التعديلات الحالية تُحفظ في LocalStorage على نفس المتصفح والجهاز فقط.

## مهم قبل النشر الفعلي
هذه نسخة Front-end أولية. لوحة الإدارة الحالية ليست متعددة الأجهزة ولا تحتوي على تسجيل دخول آمن أو قاعدة بيانات مشتركة. لكي تظهر تعديلات لوحة الإدارة لجميع العملاء، يجب ربط المشروع بقاعدة بيانات مثل Supabase، وإضافة Authentication وصلاحيات آمنة وStorage للصور. كذلك يجب التحقق من الطلبات يدويًا على واتساب؛ لا يوجد تأكيد دفع إلكتروني في هذه النسخة.


## تحديث الهوية والتوصيل
- الهوية البصرية: أحمر وأبيض.
- عنوان الهايبر: المهندسين، شارع وادي النيل.
- مناطق التوصيل: العجوزة 30 جنيه، المهندسين 25 جنيه، ميت عقبة 15 جنيه، ميدان لبنان 25 جنيه.
- يختار العميل المنطقة، وتحسب رسوم التوصيل تلقائيًا.
- رسالة واتساب تتضمن اسم العميل ورقم الهاتف والمنطقة والعنوان والمنتجات والكميات والإجمالي وطريقة الدفع والملاحظات.
- صور المنتجات تستخدم روابط صور فوتوغرافية من Unsplash CDN وتتطلب اتصال إنترنت.
